# 나침반 — 진로와 세특을 잇다

고등학생이 성적과 세특을 정리하고, 탐구 아이디어와 다음 학습 단계를 살펴보는 한국어 웹 앱입니다.

## 실행

Node.js 20 이상이면 별도 패키지 설치 없이 서버를 실행할 수 있습니다.

```powershell
Copy-Item .env.example .env
# .env 파일에 GEMINI_API_KEY를 입력한 다음 저장
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 여세요. Gemini 키를 설정하지 않아도 로컬 분석 모드로 실행됩니다. 서버 없이 쓰려면 `index.html`을 브라우저에서 직접 열면 됩니다.

## 포함 기능

- 학생 프로필, 관심 키워드, 과목별 등급과 세특 입력
- 입력 내용을 바탕으로 한 로컬 기본 진단과 성장 피드백
- 지원 전략 탐색 카드, 과목 연계 탐구 주제, 학습 자료 출발점
- 클릭 가능한 진로 로드맵
- 브라우저 인쇄 창을 이용한 A4 리포트 및 PDF 저장
- 분석 후 프로필과 결과를 브라우저 `localStorage`에 저장

## 데이터와 분석 안내

- 기본 분석은 브라우저에서 키워드와 입력 분량을 이용해 동작하는 규칙 기반 피드백입니다.
- `.env`에 Gemini 키를 설정하고 서버로 접속한 경우에만, 분석 요청 시 이름을 제외한 세특·성적·관심 분야가 Gemini API로 전송됩니다. API 키는 서버에서만 읽으며 브라우저에 노출하지 않습니다.
- Gemini는 강점·보완점·탐구 아이디어를 생성합니다. 진단 점수와 지원 탐색 점수는 로컬 계산이며 대학별 모집 요강이나 입결 자료에 연결되지 않습니다. 점수는 합격 확률이 아닙니다.
- 입력 프로필과 분석 결과는 브라우저의 로컬 저장소에도 저장됩니다. Gemini를 연결한 경우 요청한 분석 내용은 Google Gemini API로도 전송됩니다. 공용 기기라면 사용 후 브라우저 데이터를 지우세요.

Gemini는 JSON 구조화 응답을 사용합니다. [Google의 구조화 출력 문서](https://ai.google.dev/gemini-api/docs/structured-output)를 참고하세요.

## 파일

- `index.html` — 화면 구조
- `styles.css` — 반응형 디자인과 인쇄용 스타일
- `app.js` — 입력, 로컬 분석, 결과 표시, 저장 및 인쇄 기능
- `server.mjs` — 정적 파일 서버와 선택적 Gemini API 연결
